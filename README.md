# Lab 02 — Open the Box

This repository contains my solution for Lab 02 — Open the Box.

## Description

In this laboratory work, I explored the internal behavior of the GPT-2 small language model.

The lab includes:

- GPT-2 tokenizer and tokenization
- Next-token prediction
- Temperature and probability distribution
- Top-p sampling
- Attention mechanism
- Previous-token attention heads
- Attention sink
- Tokenization of English, Russian and Kazakh text

## Model

The laboratory uses GPT-2 small with approximately 124 million parameters.

## Files

- `lab02_inside_the_model.ipynb` — completed laboratory notebook
- `README.md` — project description
